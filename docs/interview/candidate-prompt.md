# 面试项目：SaaS 租户管理

## 你的角色

你是 SaaS 平台团队的工程师。面试官扮演业务需求方，并会分阶段给出需求。每一阶段开始时才会收到该阶段的任务；请先澄清当前阶段的业务规则，然后实现当前目标，不需要猜测后续阶段。

## 面试约定

- 整个练习约 30–40 分钟；面试官会在过程中逐段发送任务说明。
- 本练习会观察你如何使用 Vibe Coding 工具。请至少在一个阶段实际使用你熟悉的 AI 编码助手；不限定工具。你需要阅读、审查并验证自己保留的改动，并能说明关键代码为什么这样改。
- 请简要讲出你的计划、假设、进度和风险；不清楚的业务规则可以向需求方提问。
- 保持 Git 改动小而易审查，为你实现的行为补充测试。
- 本地演练身份仅用于本地测试，不要添加真实身份服务凭证或把数据发送给外部服务。
- 请在面试前 clone 仓库并运行对应系统的 `scripts/start-interview` 启动脚本，确认项目可以启动；首次运行需 Git、互联网连接和现代浏览器，会下载项目本地 Node.js 并安装依赖，环境准备不计入面试时间。如果网络策略阻止下载，请安装 Node.js 24.x 后告知面试官。
- 最后展示完成的行为、运行过的检查和仍然存在的风险。

- 面试官可能在三个必做阶段结束后提供可选加分题；加分题不影响必做阶段的通过判定。

仓库已经包含可运行的 React 前端、REST API、PostgreSQL 数据库、预置身份和基础页面。首次启动需要 Docker Desktop，启动脚本会自动运行本地 PostgreSQL。macOS/Linux 使用 `./scripts/start-interview.sh`；Windows PowerShell 使用 `./scripts/start-interview.ps1`。在浏览器打开 `http://127.0.0.1:5173/`，按 `Ctrl+C` 停止前后端；PostgreSQL 容器继续运行。请先运行项目，再开始当前阶段的任务。需要运行检查时，macOS/Linux 使用 `./scripts/npm.sh`，Windows PowerShell 使用 `./scripts/npm.ps1`；例如 `./scripts/npm.sh run test:challenge` 只对应第一阶段。


## Okta/OIDC

真实 Okta/OIDC 集成不属于限时编码任务。面试官可能在最后询问如何把本地演练身份接入 Okta/OIDC，以及怎样将外部身份安全地映射到本地用户、租户和角色。
